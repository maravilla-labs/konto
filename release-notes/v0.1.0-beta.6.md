# Encryption at Rest

This release encrypts your data on disk. The database, every uploaded file, and the app's signing secret are now protected with AES-256 — so a lost or stolen laptop, a copied data folder, or a backup pulled off the disk no longer exposes your books. Existing data is encrypted automatically on first launch; you don't have to do anything.

## Highlights

- **Database encrypted with SQLCipher** — Your entire accounting database is now AES-256 encrypted at the page level. Encryption sits below the application, so nothing about how you work changes — the data is simply unreadable without the key.
- **Uploaded files encrypted too** — Receipts, invoice attachments and avatars are individually encrypted with AES-256-GCM. No financial document sits in plaintext on disk anymore.
- **Transparent by default** — The encryption key is generated once and kept in your operating system's keychain (macOS Keychain, Windows Credential Manager, Linux Secret Service). The app unlocks itself on launch — no password to remember, protection against disk and backup theft.
- **Optional master password** — Want zero-knowledge protection? Go to **Settings → Security** and set a master password. The database can then only be opened by entering it on launch, and it never touches the disk in any recoverable form. Note: a forgotten master password cannot be recovered, so store it safely.
- **Server-ready** — Self-hosted deployments supply the key via the `KONTO_MASTER_KEY` environment variable, the same way the database URL and JWT secret are injected, so the same protection works headlessly.

## Heads-up for existing beta users

- On the first launch after updating, your existing database and uploaded files are converted to encrypted form in place. For large datasets this can take a few extra seconds at startup. No plaintext copy is left behind.
- The app signing secret moves from a file into your OS keychain automatically.
- Everything else — your data, settings and login — carries over unchanged. The in-app updater handles this release normally.
