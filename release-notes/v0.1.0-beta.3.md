# Windows Welcome Screen & macOS Build Fixes

This release fixes two issues that blocked the previous beta from reaching Windows and macOS users.

## Fixes

- **Windows: welcome screen now appears on first launch** — The embedded API server's CORS allowlist was missing `http://tauri.localhost`, which is the origin used by Windows WebView2. As a result, the `/setup/status` request was blocked and the account-creation wizard never rendered. Windows users can now complete onboarding normally.
- **macOS: build now produces a working DMG** — Beta builds use ad-hoc signing, but empty Apple notarization credentials were still being forwarded to the bundler, which aborted with `Team ID must be at least 3 characters`. Notarization env vars are now only set when a real Apple certificate is configured, so ad-hoc beta builds complete end-to-end.
