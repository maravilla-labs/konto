# Multi-Currency Projects, Invoices & FX Booking

Projects, invoices, and bank accounts now share one real currency model instead of a disconnected free-text field — and foreign-currency invoices are booked correctly, with FX gain/loss recognized only when currency is actually converted.

## Highlights

- **Currency is now a proper dropdown everywhere** — Projects, invoices, and bank accounts all pick from the currencies configured in **Settings → Currencies**, instead of typing a code by hand.
- **Default bank account per currency** — Each currency can have a default bank account (Settings → Currencies), which invoices pick up automatically and can still override per invoice.
- **Correct multi-currency booking** — Sending a foreign-currency invoice now books the ledger entry converted to your base currency, using the exchange rate valid on the issue date, while preserving the original face-value amount for reference.
- **No premature gain/loss** — Paying an invoice into a bank account in the same currency just moves the value at the invoice's original rate. Nothing is recognized as a gain or loss until money is actually converted.
- **Realized FX gain/loss on conversion** — A new **Currency Exchanges** page (Settings) records transfers between bank accounts of different currencies at the real rate you received, and books the realized gain or loss automatically using each account's own weighted-average cost history.
- **Exchange rates, wired up** — Invoice and payment booking now look up the latest applicable rate automatically. A **Fetch Latest from ECB** button in Settings → Exchange Rates pulls the European Central Bank's public daily reference rates with one click; manual entry still works as before.

## Heads-up for existing beta users

- Existing projects are migrated automatically: their free-text currency is matched against your configured currencies on first launch after updating.
- Settings → Bank Accounts now lets you assign each account's currency — do this once so invoice and payment booking pick the right accounts automatically.
