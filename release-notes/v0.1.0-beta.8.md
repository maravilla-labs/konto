# Fix: App Fails to Start After Updating to beta.7

A bug fix release. **If beta.7 stopped opening for you, this release fixes it — your data is intact and no action is needed beyond updating.**

## What went wrong

Beta.7 introduced the new currency model and migrated each project's old free-text currency to a proper currency reference on first launch. If any project's currency had been typed by hand as a symbol (for example `€`) rather than a code like `EUR`, that migration stopped halfway. Part of the change had already been written to the database, so every following launch tried to redo it, failed the same way, and the app quit before its window ever appeared — with no error message at all.

## What's fixed

- **The migration now completes.** Currencies are matched by code, by symbol, and by a table of common symbols (`€ $ £ ¥ Fr. SFr.`), so hand-entered values are recognized. It also picks up cleanly from a half-finished run, which is what unblocks affected installs.
- **An unrecognizable currency no longer stops anything.** Those projects simply come through with their currency unset — open the project and pick one from the dropdown. Everything else migrates normally.
- **Startup problems are now shown, not swallowed.** If the app ever fails to start, it opens a window explaining what happened, with the details available to copy, instead of disappearing silently. Your data is never modified when startup fails.
